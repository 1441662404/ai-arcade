山路 · 第一人称座舱驾驶

方向盘、挡把、中控屏、车门车窗——全部用准星直接抓 3D 模型操作，没有 UI 按钮代替。

操作方式

准星 = 手
鼠标移动准星，移到哪里就操作哪里（方向盘 / 挡把 / 中控屏 / 车门把手 / 车窗开关）
转向
准星对准方向盘 → 按住左键 → 以方向盘中心为圆心画圆，方向盘跟着转，车就转弯。松手自动回正
换挡
准星对准挡把 → 按住左键（挡把亮起抖动）→ 踩离合 A → 拖动鼠标走 H 挡位槽 → 到位后松开 A 结合离合
踏板
A 离合（屏幕左下三个踏板条实时显示）· S 刹车 · D 油门
中控屏
准星点屏幕上的按钮：车灯 / 双闪 / 音乐 / 导航。电台里有 山路 Eurobeat 固定歌单（Running in the 90s / Deja Vu / Dogfight …）
联机
同一个网址打开就在同一个房间（右上「联机」显示人数）——想换房就在地址后面加 #房间名。别的玩家会显示成半透明幽灵车
车门车窗
点左门内把手开门，点车窗开关（或直接点玻璃）升降窗
其他键
E 点火（需踩离合）· 空格 手刹 · C 视角回正 · R 回到路面 · L 鼠标锁定 · H 帮助
视角
按住鼠标右键拖动自由转头看风景；抓方向盘 / 挡把时视角会自动看向该处
提示：起步——踩离合 A → 挂 1 挡 → 轻给油门 D（1500rpm 左右）→ 慢松 A。松太快会熄火。
下山用低挡位拖住车速，别一路踩刹车。撞护栏会掉速，掉出赛道按 R 回到路面。
