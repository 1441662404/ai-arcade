本地运行任意一款
需要 Node.js 18+ · 每款游戏独立，互不依赖 
# 进入任意游戏目录
cd Nbike
npm install
npm start        # → http://localhost:3000

# 想同时开两款，用 PORT 指定不同端口
PORT=3001 npm start

# 沉浸驾驶是纯前端，无需安装依赖
cd 沉浸驾驶 && npm start
